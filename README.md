# Tabvanta Free

**Windows file dialogs, fixed.**

Tabvanta improves the Windows Open and Save experience with tabs, pinned locations, recent folders, faster navigation, familiar Windows-style controls, and a cleaner workflow for people who spend all day digging through the same directory trees.

## What Tabvanta Free includes

- Tabbed Open/Save workflow
- Pinned and frequently used folders
- Recent-path history
- Quick Access and drive navigation
- Windows-style file and folder views
- Light and dark interface support
- Native-feeling context menus and navigation
- Free permanent license key

## Free vs Pro

This repository is for **Tabvanta Free**. Tabvanta Pro includes additional paid features and is distributed separately through the official Tabvanta website.

A Free license can later be upgraded to Pro without replacing the customer's existing license key.

## Downloads
